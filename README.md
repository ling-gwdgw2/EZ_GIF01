# NovaGIF Studio 🎞️ (EZ_GIF01)

เครื่องมือจัดการ จัดระเบียบ สร้าง และแปลงไฟล์ GIF/มัลติมีเดียบนเบราว์เซอร์สไตล์ **Retro 8-Bit / Arcade Neon Glassmorphic** 

 **ลิงก์เข้าใช้งานแอปพลิเคชันออนไลน์:** [https://ling-gwdgw2.github.io/EZ_GIF01/](https://ling-gwdgw2.github.io/EZ_GIF01/)

---

## ข้อมูลทั่วไปของโปรเจกต์ (Overview)
**NovaGIF Studio** เป็นเครื่องมือแบบ Single Page Application (SPA) ที่พัฒนาขึ้นโดยใช้ **React + TypeScript + Vite** โดยมีคุณสมบัติเด่นดังนี้:
1.  **Client-Side 100%:** ทุกการแปลงไฟล์วิดีโอ การแปลงภาพ หรือการบีบอัด จะกระทำบนฝั่งเบราว์เซอร์ของผู้ใช้โดยตรง ไม่มีการส่งข้อมูลใด ๆ ขึ้นสู่เซิร์ฟเวอร์ภายนอก ปลอดภัยในเรื่องความเป็นส่วนตัวและความเป็นส่วนบุคคลสูงสุด
2.  **ดีไซน์สไตล์ Retro:** หน้าจอการทำงานได้รับอิทธิพลจากธีมตู้เกมอาร์เคดย้อนยุค 8-bit ใช้ชุดสี Neon, ขอบการ์ดสไตล์ Glassmorphism และเอฟเฟกต์ Glow ที่สวยงามสะดุดตา
3.  **ประมวลผลเป็นคิว (Sequential Processing):** มีการบริหารจัดการคิวและ Web Workers ป้องกันปัญหาเบราว์เซอร์ค้างหรือแจ้งเตือนกระบวนการทำงานหนักเกินไป

## ฟีเจอร์ที่ได้รับการอัปเดตและปรับปรุง (Enhanced Features)

*   **Drag & Drop Frame Reordering ใน GIF Maker:** ปุ่มจัดลำดับเฟรมเลื่อนซ้าย-ขวาแบบเดิมถูกแทนที่ด้วยระบบคลิกลากรูปภาพสลับตำแหน่งได้ทันทีตามต้องการ มาพร้อมกรอบจุดประ retro และ scale ฟีดแบ็กเมื่อลากผ่านเฟรมเป้าหมาย
*   **ระบบแปลงไฟล์เป็นกลุ่ม (Batch Conversion):** หน้า Universal Converter สามารถรับรูปภาพหรือไฟล์เสียงได้ทีละหลาย ๆ ไฟล์พร้อมกัน ทำการประมวลผลต่อกันเป็นคิวอัตโนมัติ และบีบอัดดาวน์โหลดรวมทุกผลลัพธ์เป็นไฟล์ `.zip` ได้ในคลิกเดียวผ่านไลบรารี `jszip`
*   **ระบบป้องกันเบราว์เซอร์ค้าง (Process Trimming Warning):** ตรวจจับการประมวลผลช่วงเวลากลางวิดีโอ หากระยะเวลาส่วนตัดยาวเกิน 15 วินาที จะแจ้งเตือนผู้ใช้ถึงโอกาสการค้างของหน้าจอและแนะนำวิธีบีบอัดอย่างเหมาะสม
*   **ระบบ SVG Size Fallback:** ตั้งค่าขนาดภาพสำรองอัตโนมัติ `400x400 px` ป้องกันการวาดภาพลง Canvas ล้มเหลวกรณีไฟล์ต้นทาง SVG ไม่มีมิติข้อมูลเริ่มต้น
*   **แก้ไขระบบ GIF Frame Splitter:** อัปเกรดตัวประมวลผลให้อ่านข้อมูลไบนารีระดับอาร์เรย์ (`ArrayBuffer`) โดยตรง ป้องกันการแยกเฟรมผิดพลาดได้ 100%

## รายการไลบรารีที่จำเป็น (Tech Stack)
*   **Framework:** React 19 + TypeScript + Vite
*   **Icons:** Lucide-React
*   **GIF Engines:** gifshot (สร้างและประมวลผล GIF), gifuct-js (แยกข้อมูลเฟรมภาพ GIF)
*   **Utilities:** jszip (สร้างไฟล์บีบอัด Zip สำหรับชุดแปลงรูปภาพ), jspdf (ส่งออก PDF)
*   **Deployment:** gh-pages (เครื่องมือส่งซอร์สโค้ด Build ขึ้น GitHub Pages)

## วิธีการติดตั้งและรันโปรเจกต์ (Installation & Quickstart)

เมื่อทำการโคลนโปรเจกต์นี้มาแล้ว สามารถตั้งค่าใช้งานผ่าน Terminal ได้ดังนี้:

### 1. ติดตั้งไลบรารีในเครื่อง
```bash
npm install
```

### 2. รันโปรเจกต์ในโหมดพัฒนา
```bash
npm run dev
```
*เปิดเปิดเบราว์เซอร์ของคุณไปที่ [http://localhost:5173](http://localhost:5173)*

### 3. ตรวจสอบ Syntax คำสั่งและสแกนข้อผิดพลาด
```bash
npm run lint
```

### 4. คอมไพล์โปรเจกต์เตรียมใช้งานจริง
```bash
npm run build
```

### 5. อัปโหลดเว็บขึ้นเผยแพร่ (Deploy) บน GitHub Pages
```bash
npm run deploy
```
*ระบบจะสร้างโฟลเดอร์ `dist` ใหม่ แล้วนำข้อมูลไปพุชไปยัง branch `gh-pages` บน GitHub ให้อัตโนมัติ*
